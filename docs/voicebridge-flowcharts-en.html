FLASK · PYTHON · SQLITE

Backend architecture.

Requests enter the API layer. Services run the feature. db.py handles SQLite, while Flask calls the external APIs it needs.

Feature requests require the Flask access JWT in the Bearer header. Flask verifies its signature, issuer, audience, expiry, and active SQLite session; logout revokes that session immediately. The Google login challenge and Google sign-in endpoints are public. OpenAI and Gemini keys, JWT_SECRET_KEY and the Sheets service account credentials stay on the backend.
