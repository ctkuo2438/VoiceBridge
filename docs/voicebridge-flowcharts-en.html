FLASK · PYTHON · SQLITE

Backend architecture.

Requests enter the API layer. Services run the feature. db.py handles SQLite, while Flask calls the external APIs it needs.

Feature requests require the Flask Bearer token. The Google login challenge and Google sign-in endpoints are public. Keys and service account credentials stay on the backend.

Based on api/, services/, and db.py in VoiceBridge. Database: instance/voicebridge.sqlite3. Same outlined style as the companion guide; light mode and printing are available.
