Three things to remember about identity and data

Google ID token → identity

Google signs this JWT as proof of identity. Flask verifies its signature, audience, expiry, and nonce before accepting the login. The nonce is a one-use login check, valid for five minutes.

Flask App JWT → app access

Flask signs its own HS256 JWT using a backend-only secret. Its claims include sub (user), sid (session), iat, exp, iss, and aud. Protected requests verify the signature, claims, and active SQLite session. SessionStore keeps the JWT in memory; OkHttp adds Authorization: Bearer <App JWT>. SQLite stores a hash, so logout can revoke the session before the JWT expires.

user_id → lasting history

Chats and memos belong to a stable user_id. A later login creates a new session but resolves the same user. SQLite keeps chat messages and notes; Google Sheets logs user prompt text. Sheet writes use Flask's service account credentials.
