Three things to remember about identity and data

Google ID token → identity

Google signs this proof of identity. Flask verifies its signature, audience, expiry, and nonce before accepting the login. The nonce is a one-use login check, valid for five minutes.

Flask token → app access

Flask signs its own app access JWT using a backend-only secret. It verifies the signature, issuer, audience, expiry, and active SQLite session on protected requests. Android keeps it in SessionStore; OkHttp adds it as an Authorization: Bearer header on protected app requests. SQLite stores a hash. The default session lasts 24 hours or until logout.

user_id → lasting history

Chats and memos belong to a stable user_id. A later login creates a new session but resolves the same user. SQLite keeps chat messages and notes; Google Sheets logs user prompt text. Sheet writes use Flask's service account credentials.
